# Abhoy Mallik · Portfolio

**Live:** https://abhoy84.github.io/ · **CV:** https://abhoy84.github.io/assets/cv/Abhoy_Mallik_CV.pdf

"One Codebase, Four Platforms": a portfolio that re-skins itself as Android, iOS, Windows and macOS, just like a Flutter app.
Plain HTML, CSS and a little vanilla JavaScript. No framework, no build step.

## Quick start

```powershell
git clone https://github.com/Abhoy84/Abhoy84.github.io.git
cd Abhoy84.github.io
python -m http.server 5500      # or VS Code → right-click index.html → Open with Live Server
```

Open http://localhost:5500, edit, then:

```powershell
git add -A
git commit -m "Describe your change"
git push                         # live in about a minute
```
